# BUILDER 数学AIチュータ 体験モック

計算・式変形・方程式を題材に、AIチュータの学習支援の画面と動線を検討するプロトタイプです。

## 試す

[ブラウザでモックを開く](https://naokitakahashi19.github.io/builder-math-tutor-mock/)

`index.html` をダウンロードしてブラウザで開いても動きます。ビルドやサーバーは不要です。

1. ページ・大問・小問を選びます。
2. 「解き方のヒント」から解法ステップを進め、必要に応じてヒントを深掘りします。
3. 「分かった」の後はノートで続きを解き、同じステップへの再相談や次のステップへ進めます。
4. 「解答を見て」→「ノートを撮る」→撮影ボタンで、答案例に対する支援を体験できます。

画面下部の「モック確認用」で、次の操作への迷い・操作の選び方の誤り・計算の誤りの3ケースを切り替えられます。「設計確認」では問題取込時の事前分析を想定したステップを確認できます。

## 実装状況

- 6問・20ステップと、18ケースの写真相談を固定データで再現しています。
- 問題の事前分析、対話、画像認識を行うAIは未接続です。
- カメラ画面は模擬体験です。撮影ボタンは答案例を表示します。
- 選択した写真はブラウザ内で表示するだけで、サーバーには送信しません。
- 実装時は別の正しい解法も扱い、標準の順番との差だけで誤りとは判定しない設計を想定しています。
